---
name: implement-feature
description: Implement a small feature using the project's engineering workflow.
---
1. Restate requirement and acceptance criteria.
2. Inspect models, serializers, views, URLs, and tests.
3. Propose a minimal plan.
4. Add tests for expected behavior and invalid input.
5. Implement the smallest change.
6. Run Django checks, tests, Ruff and inspect diff.
7. Report only checks actually run; do not commit or deploy without permission.
